# Genesis — Эрдэнэт Сурагч Транзит & Ухаалаг Төлөвлөгч

Орхон аймаг / Эрдэнэт хотын сурагчдад зориулсан өглөөний автобусны чиглэл, сургуулийн ойрын буудал, гэрээс гарах цаг болон өдрийн төлөвлөгөөг (`Daily Planner`) нэг дор уялдуулсан вэб аппликейшн.

## Гол боломжууд
* **Сургууль ба чиглэлийн зөвлөмж:** Эрдэнэтийн сургуулиудыг сонгоход тухайн сургуулийн ойрын буух буудал болон буудлаас сургууль хүртэл алхах хугацааг харуулж, тохирох автобусны чиглэлийг автоматаар санал болгоно.
* **Автобусны байршил ба хөдөлгөөн:** Сонгосон чиглэлийн буудлуудын дагуу автобус хаана явж байгааг дүрслэн харуулна.
* **Гарах цагийн тооцоолол & Саатлын шийдэл:** Хичээл эхлэх цаг, алхах хугацаа, замын/цаг агаарын нөхцөл болон нөөц хугацааг тооцоолж гарах оновчтой цагийг гаргана; сааталтай үед өөр хувилбар болон төлөвлөгөөний цаг хойшлуулах сонголт өгнө.
* **Daily Planner:** Ажил/төлөвлөгөө нэмэх, дууссаныг тэмдэглэх болон шаардлагагүй зүйлийг устгах/хасах боломжтой цэвэрхэн төлөвлөгч.
